# Programar en YouTube Studio (#008 al #017)

Cómo: YouTube Studio → Crear → Subir video → pega título, descripción y etiquetas →
"No, no es contenido para niños" → "Contenido alterado o sintético: Sí" →
Visibilidad: **Programar** con la fecha y hora de abajo (hora de Tijuana).

Archivo de cada video: carpeta `sin-coartada/short-XX-.../short.mp4` (o pídelo y te lo mando).

Facebook ya está programado solo; esto es solo para YouTube.
